# 红警塔防 · 网页原型 v0.2

双击 `index.html` 就能玩，不用装环境、不用起服务器。

v0.2 的核心变化：**没有固定路径了**。敌人从地图边缘的五个入口进来，自己找路走向基地；你的建筑就是路。

---

## 一、这一版玩了什么

| 机制 | 说明 |
|---|---|
| **自由寻路** | 敌人不从固定路线走，从任何方向都能来，路线由你的建筑决定 |
| **多入口** | 西北 / 正北 / 东北 / 正西 / 正东，五个方向。波次越高开得越多 |
| **建筑有尺寸** | 1×1 碉堡、2×2 电厂兵营、3×3 重工实验室、4×4 基地 |
| **拆墙** | 你用建筑把路堵死，敌人就自己拆出一条路。拆的过程就是你的输出窗口 |
| **断生产链** | 兵营被拆 → 立刻造不出步兵；战车工厂被拆 → 造不出坦克 |
| **牵引追击** | 单位会主动出击，但不会追出自己的圈，打完自动回原位 |
| **指挥单位** | 点选己方单位 → 点地图空地 → 它走过去驻扎。打完仗自动回到这个新位置 |
| **音效与 BGM** | 全部用 Web Audio 现场合成，不加载任何音频文件。首次点击页面后自动开启 |
| **触屏可玩** | 单指平移 / 双指缩放 / 单指选择，配「取消 · 同类 · 回基地」三个指挥键（§11） |
| **响应式外壳** | 竖屏底部抽屉 + 分组标签，矮横屏右侧窄栏，桌面不变（§11.2） |
| **电力 = 人口** | 电厂 200 电，步兵占 1、坦克占 3、天启占 6。断电全场射速 -30% |
| **老兵晋升** | 3 杀升老兵（+50% 伤害），8 杀升精英（+100% 且自愈） |
| **克制矩阵** | 小口径打重甲只有 25%。打不动时目标身上会飘"无效" |

## 二、文件结构

按「改这块只动这个文件」来切：

```
web/
├── js/data/          ★ 纯数值，调平衡只改这里
│   ├── units.js           8 兵种 + 7 建筑（含尺寸、牵引半径、移速）
│   ├── waves.js           敌人属性 + 12 波编排（含每波从哪几个入口来）
│   └── damage.js          弹头 × 护甲克制矩阵
├── js/core/          ★ 纯逻辑，零渲染代码
│   ├── config.js          全局常量
│   ├── view.js            投影层 + 摄像机：世界格子 ↔ 屏幕像素（平面正交）
│   ├── map.js             基地位置、五个入口
│   ├── field.js           流场：敌人往哪走全在这一个文件里
│   ├── battle.js          选目标、算伤害、拆墙判定、牵引追击
│   └── audio.js           音效与 BGM，Web Audio 现场合成
├── js/game/          状态 / 经济 / 波次调度
├── js/render/
│   ├── scene.js           布局与流程：什么画在哪、按什么顺序
│   ├── pixel.js           造型：字符网格 → 调色板 → 一张图集，纯代码像素
│   ├── hud.js             DOM 界面（含窄屏分组标签、指挥快捷键）
│   └── input.js           指针层：鼠标 / 触屏 / 键盘走同一套代码
└── main.js           固定步长的主循环
```

`core` 和 `data` 里没有一行画面代码 —— 这是为自走棋模式留的，到时直接复用这两个目录，只写新的调度层。

## 三、流场是怎么让敌人自己找路的

不给每个敌人单独寻路（几十个单位同时算会卡）。做法是：

1. 以基地为唯一源点，用 Dijkstra 向全图扩散，给每一格算一个「走到基地要花多少代价」
2. 敌人每一步只问一句「我旁边哪边数字最小」，朝那边走
3. 建筑一放，这张表重算一次。36×24 = 864 格，毫秒级

**关键设计：建筑不是硬阻挡，而是「贵」。**

空地走一格 = 1，穿过一格建筑 = 16。于是：

- 没围死的时候，绕两格（2）远比拆墙（16）便宜 → **敌人自动绕开**
- 完全围死的时候，唯一的出口就是最薄的那面墙 → **敌人自己走过去拆**

一个距离场同时解决「绕路」和「砸哪面墙」两个问题，不需要两套逻辑。想调这个平衡，改 `field.js` 里的 `BREACH_COST`：调高敌人更爱绕路，调低敌人更爱拆墙。

**按 F 键**可以打开流场热力图，绿得越亮表示离基地越近。

## 四、建筑尺寸的战术含义

尺寸不是为了"占更多格子"，是为了让玩家做不同的决策：

| 尺寸 | 建筑 | 战术含义 |
|---|---|---|
| 1×1 | 机枪碉堡、光棱塔、磁暴线圈 | 灵活，能塞墙角补漏，用来微调敌人路线 |
| 2×2 | 电厂、兵营 | 防线的砖块，性价比最高 |
| 3×3 | 战车工厂、作战实验室 | 放下去整片地形就变了，逼你提前规划 |
| 4×4 | 基地 | 敌人唯一的目标 |

关键在最后一列：**大建筑逼你提前规划，小建筑给你补救空间**。你造了 3×3 的战车工厂，那块地就永久变了，周围的防线得围着它设计。

## 五、牵引半径 = 兵种性格

单位记住自己的驻扎点，敌人进射程就冲上去，但追击位置不会超出以驻扎点为圆心的牵引半径。

| 单位 | 牵引 | 为什么 |
|---|---|---|
| 灰熊坦克 | 8 格 | 全场最快，敢追 |
| 多功能车 | 6 格 | 跑得快，射程远 |
| 犀牛坦克 | 5 格 | 主力，稳一点 |
| 美国大兵 / 动员兵 | 4 格 | 追太远就是送 |
| 谭雅 | 3 格 | 怕坦克，不该追 |
| 光棱坦克 | 2 格 | 怕贴脸，几乎黏死在阵地上 |
| 天启坦克 | 0 格 | 原地不动，专治突进 |

玩家不用看数值表，看谁冲出去就知道谁的定位。

### 5.1 怎么指挥单位

左键点己方单位 → 出现黄色四角框和一条虚线（线连到它当前的驻扎点）→ 再点地图空地，就换了阵地。

- 它自己走过去，路上遇到敌人会先打，打完继续走
- 走过去之后就以新位置为家，下一次出击还从这里出发
- 右键或 Esc 取消选择。**注意选中单位时右键是取消，不是拆掉它**
- 建筑不能指挥；天启能移动但不主动追击（牵引半径 0）

`?cmd=1` 可以直接看到这个界面。

### 5.2 触屏上怎么指挥

手机上没有右键，也没有 Esc，所以指挥靠地图上悬浮的三个按钮（`#cmd-bar`）：**取消 / 同类 / 回基地**。

- 点自己单位 = 选中；选中状态下再点空地 = 换防
- 「同类」把当前选中单位的**同兵种全部**收进 `state.squad`，然后点一次空地就整队换防，toast 报「6 个单位换防」
- 没选中单位时按「同类」= 场上所有可移动单位一起选
- 「回基地」把摄像机拉回基地并 toast 提示

渲染上，一队人每个都画黄色四角框，只有领队保留虚线归位线（`scene.js` 的 `drawCommand`）。

## 六、怎么改

```bash
node tools/simulate.js 8      # 无头跑 8 局，输出通关率
node tools/test_breach.js     # 验证"围死基地 → 敌人拆墙"
node tools/test_rich.js       # 给无限资金，测引擎上限（目前 43 单位满血通关）
```

改完数值跑一下，比手动试快得多。觉得太难或太简单，优先动 `waves.js` 的数量，其次 `config.js` 的 `START_MONEY` 和 `WAVE_CLEAR_BONUS`。

**当前基准**：AI 跑 12 波 **4/8 通关**，通关时基地剩 22%~74%。AI 不会造围墙、不会挑地形，真人应该明显更宽松。

## 七、这版故意留空的

- **建筑被拆时没有废墟提示**，玩家可能没意识到兵营没了导致造不出兵
- **建造时看不到"放下去之后敌人会走哪"**。这是自由寻路塔防最该有的一块 UI，现在只能靠 F 键看流场自己判断
- **单位还不会绕开建筑走路**，追击时撞到建筑会卡住
- 间谍、特种兵、敌方科技树发育，都还没做

下一步优先级：建造时的路线预览 > 单位绕障 > 兵营被拆的强提示。

## 八、美术：战术沙盘

完整规格见 `art/hongjing-美术风格提案.md` 与 `art/hongjing-美术资产清单.md`。这里只说实现在哪。

### 8.1 三条不可随手改的规则

| 规则 | 在哪实现 | 为什么 |
|---|---|---|
| **双层结构**：物质层有投影/噪点/两段明度，标注层纯色无投影 | `drawBuilding` 三层绘制 vs `hpBar` / `drawPreview` | 玩家靠"有没有投影"区分"场景物件"和"界面提示" |
| **阵营靠形状**：玩家圆底座、敌方六边形底座 | `drawUnit` 里的 `hexPath` | 去色也分得出敌我，不只靠红蓝 |
| **实体与地面明度差 ≥ 30** | 地面 L14~20，建筑 L46，单位 L49 | 差的这 30 就是"物件浮在沙盘上"的来源 |

### 8.2 想改哪里

| 想改 | 改哪 |
|---|---|
| 地面材质、地形形状、网格亮度、入口箭头 | `scene.js` 的 `buildBackground()` |
| 建筑三层颜色、标识样式 | `scene.js` 的 `drawBuilding()` / `drawEmblem()` |
| 单位剪影形状 | `scene.js` 的 `drawSilhouette()`，一个 `case` 一个单位 |
| 单位底座大小、阵营色 | `scene.js` 的 `drawUnit()` |
| 一套色号 | 见风格提案 §3，全项目统一，不在各文件里散落 |

### 8.3 已完成的批次

- **B0 地面**：沙丘斑块 + 等高线 + 砂砾噪点 + 网格压暗 + 入口改军事地图箭头
- **B1 建筑**：投影/侧面/顶面三层 + 顶视结构（厂房、屋顶、卷帘门、穹顶、沙袋环、塔身、线圈）+ 顶面功能色 + 占地格线
- **B2 单位**：底座（圆/六边形）+ 13 个三色造型（履带 / 车体 / 炮塔 / 炮管分开上色）+ 按目标转向
- **B3 特效**：按武器分五种手感 —— 步枪曳光弹、坦克炮口闪光 + 炮弹 + 爆炸圈、光棱光束、磁暴锯齿电弧、谭雅斩击

### 8.4 造型和布局是分开的

- `pixel.js` —— 造型。步兵是一个个字符网格（一行一像素，手写剪影）；车辆的车体走参数化 `hullOf()`（履带、格栅、斜甲板、车灯是重复内容，手写只会数错格子），炮塔仍然手写，因为识别特征全在炮塔上；建筑是参数化的。运行时一次性烘成一张图集。
- `scene.js` —— 决定画在哪、画多大、按什么顺序，只调 `stampCentered(key, x, y, U)`。

四条朝向（S/E/N/W）：步兵手写 S/N/E，W 由 E 水平镜像；车辆手写 hull-S + turret-S，其余朝向由整数倍旋转得到。车体和炮塔分开贴，所以「车往一边走、炮往一边瞄」是免费的。

约定：车头朝下（S）是「前」。放大只允许整数倍最近邻（`U = zoom × dpr`），任何半像素都会糊成一团。

分开的原因很简单：改美术不该碰到布局逻辑，改布局也不该碰造型。以后想换一套贴图，只替换 `pixel.js` 里的网格就行。

不开浏览器也能看像素：`node tools/check-pixels.js veh:player:grizzly:S` 直接把缓冲打成终端灰度图。

### 8.5 还没做

建造清单的卡片图标还是彩色方块 + 汉字，和游戏内造型对不上。这批 UI 还没重做。

## 九、音频

`js/core/audio.js`，全部 **Web Audio 现场合成**，没有一个音频文件。

| 音效 | 触发 |
|---|---|
| 步枪 / 坦克炮 / 激光 / 电弧 / 斩击 | 按开火的 `warhead` 自动选（`HJ.Sfx.fire()`） |
| 爆炸 | 敌人被击杀 |
| 警报 | 基地被啃 |
| 建造 / 拆除 | 放建筑、拆建筑 |
| 号角 | 每波开始 |
| 胜利 / 失败 | 结算 |

BGM 是一段小调循环（Am-F-C-G），低音铺底 + 八分音符军鼓，节奏偏慢 —— 这是防守战不是冲锋。

### 9.1 两个必须知道的坑

**一、浏览器不允许无交互自动播放。** 所以音频要等玩家第一次点页面或按键才初始化。代码在 `main.js` 的 `boot()` 里挂了 `pointerdown` / `keydown` 的一次性监听。

**二、几十个单位同时开火会糊成噪声墙。** 同类音效做了 55ms 节流，否则听不出任何信息，只有"嗡嗡嗡"。

### 9.2 想调音色

全部参数在 `audio.js`：

- 整体音量：`master.gain`（0.55）
- 音效 / BGM 比例：`sfxBus`（0.75）/ `musicBus`（0.34）
- BGM 速度：`startBGM()` 里的 `60 / 92`，改 92 那个数
- 单个音色：`play()` 的 switch 里改频率、时长、滤波器

## 十、视角与坐标

现在是**平面正交俯视**：一格 = `ART`（24）个美术像素，屏幕上占多大由摄像机决定 —— `ART × zoom × dpr`，zoom 1~3 整数，画布铺满容器。手机和桌面是同一套代码，只是容器尺寸不同。

### 10.1 为什么不做了等距

试过一版等距（菱形地面 + 立方体建筑），效果不好，撤了。原因是这个游戏的显示尺寸太小：

一格 30~36 像素，单位只有 22~26 像素。斜投影会让地面可用面积再砍掉一半，而斜过来的箱子在这么小的尺寸下读不出"更高"，只读得出"歪了"。

**辨认度是这个游戏最不能牺牲的东西**——八个兵种看不出区别，克制系统就等于没做。平面俯视把每一个像素都留给剪影本身。

### 10.2 坐标怎么换算

逻辑层全是对齐格子（col/row），只有 `core/view.js` 知道怎么变成像素：

```
屏幕 = (世界 - 摄像机) × cell() + 视口中心      cell() = ART × zoom × dpr
世界 = (屏幕 - 视口中心) / cell() + 摄像机
```

CSS 像素到设备像素的换算只发生在 `fromCss()` 一处，`input.js` 拿到的坐标已经是设备像素。

留这一层不是为了现在，是为了以后：想再改视角，只动这个文件，`scene.js` 和 `input.js` 一行都不用动。

### 10.3 遮挡怎么处理

平面俯视下遮挡关系很弱，但建筑还是要压住它下方的单位，不然会有单位"浮在墙上"。

`drawEntities` 按行号排一次序，建筑用 `row + size`（占地的最后一行），保证靠下的后画。

### 10.4 建筑怎么做出体积

不用立方体，用**两段明度**：顶面一档色，上边和左边各一条亮线（受光），下边和右边各一条暗线（背光），再往右下扔一块投影。

一像素的亮暗差就够让人读出"这是立在地面上的方块"，不需要真的画侧面。

### 10.5 单位为什么没有底座

底座（玩家圆 / 敌方六边形）会让单位像"站在一个盘子上"，出戏。

现在改成：单位直接站在地面上，靠**投影椭圆**定位，靠颜色分敌我（蓝 / 红），靠**身体朝向**传达状态。

### 10.6 履带印与扬尘

- **履带印**：只有车辆留，每走半格压一道，长期留在地上（上限 420 个，超了删最旧的）
- **扬尘**：所有移动单位都扬，扩散 + 慢慢淡掉（约 0.85 秒）

生成点在 `battle.js` 的 `emitMoveFx()`，逻辑层只负责"在哪留下了什么"，画成什么样在 `scene.js`。
按走过的距离累计，不用计时器——所以跑得快的单位扬尘更密。

## 十一、手机端与响应式

### 11.1 手势表

| 操作 | 效果 | 备注 |
|---|---|---|
| 单指拖动 | 平移 | 不会误放建筑 —— 拖过就不算点击 |
| 双指捏合 | 缩放 | 只落到整数 `zoom`，锚点是两指中点 |
| 单指轻点 | 放建筑 / 选中单位 / 给选中单位指派新阵地 | 按这三者的优先级判 |
| 双指点击 | **什么都不做** | 第二根手指一落下，这一轮所有抬手都不再生成点击 |
| 鼠标滚轮 / `+ -` | 缩放 | 同上，整数 |
| 鼠标右键 | 取消选择；空地上 = 拆除 | 长按**不**触发，见下 |
| `Esc` | 取消当前选择 | |

两条判据值得单独说：

- **点还是拖，只看位移阈值**（`TAP_SLOP = 9` CSS 像素 × dpr）。不看时间 —— 手机上"慢慢按住想看清"是常事，用时间判会把平移吃掉成点击。
- **`onRightClick` 开头挡掉非鼠标指针**：触屏的长按会派发 `contextmenu`，不挡的话玩家长按地图是在拆自己建筑。

### 11.2 断点

只有一个复合断点：`(max-width: 860px), (max-height: 560px)`，命中即"紧凑模式"。紧凑模式下再分竖屏 / 横屏：

| 形态 | 侧栏 | 建造清单 |
|---|---|---|
| 竖屏（390×844） | 底部抽屉，最高 44vh | **分组标签**：全部 / 建筑 / 防御 / 步兵 / 车辆，一次只看一组；卡片 92px 竖排，隐藏属性行 |
| 矮横屏（844×390） | 右侧窄栏 | 隐藏标签，四组**全部展开**滚动，属性行留着（横屏宽度够） |
| 桌面（1100×700） | 右侧 272px | 全展开，和以前一样 |

实测：竖屏顶栏 74px + 抽屉 203px，地图占屏高约 67%；矮横屏所有 chrome 只占宽度 11%。

**为什么断点全写在 `ui.css` 末尾**：`ui.css` 是最后加载的样式表，卡片、按钮这些组件的 `padding / margin / display` 定义在它里面。把覆写放在 `layout.css` 的同一条媒体查询里，选择器权重相同，会被 `ui.css` 后面的基础规则吃掉。所以 `layout.css` 只留了一句指路注释。

### 11.3 移动端浏览器要防的事

`base.css` 里这几条不是装饰，每一条对应一个真实故障：

- `user-scalable=no` + `#game { touch-action: none }` —— 不关的话双指捏合会被浏览器抢去缩放整页，游戏收到的是被缩放后的坐标
- `overscroll-behavior: none` —— 否则拖到地图边缘会把页面下拉刷新触发
- `-webkit-tap-highlight-color: transparent` + `user-select: none` —— 点地图不再闪灰块、不再选中文字
- `viewport-fit=cover` + 顶栏 safe-area padding —— 刘海屏 iPhone 上顶栏按钮不再被圆角切掉

### 11.4 怎么验的（不开真机）

`tools/mobile-frame.html` 用三个同源 iframe 把游戏分别塞进 390×844 / 844×390 / 1100×700，由 `tools/shot-server.js`（:8799，仓库根目录）托管。布局量尺寸靠 `evaluate_script` 读 `getBoundingClientRect`，手势靠合成 `PointerEvent` 派发，最后整页截图。

```bash
node tools/shot-server.js      # 然后浏览器打开 http://127.0.0.1:8799/tools/mobile-frame.html
```

这套办法有个坑：`?demo` 世界在两次探测之间还在继续模拟，单位会死会走。测交互前先 `state.paused = true`，或直接 `HJ.Game.newGame()` 重置。
